## ✨ Tentang Proyek Ini

`GoodHealth` adalah aplikasi kesehatan berbasis mobile yang dirancang untuk mempermudah masyarakat dalam mengakses layanan medis. Aplikasi ini menjembatani pasien dengan dokter dan apotek, memungkinkan pengguna untuk menjadwalkan konsultasi serta memesan obat-obatan yang dapat diantar langsung ke lokasi.

## 🚀 Fitur Utama

`GoodHealth` menawarkan fitur-fitur yang esensial dan berorientasi pada kebutuhan pengguna modern:

### 🏥 Layanan Dokter & Janji Temu

- **Jadwalkan Pertemuan Dokter**: Pemesanan janji temu dengan dokter secara _real-time_ di berbagai spesialisasi/poli (Anak, Gigi, Umum, dll.).
- **Pilihan Poli Luas**: Memfilter dan memilih dokter berdasarkan spesialisasi, lokasi, dan jadwal ketersediaan.
- **Notifikasi Janji Temu**: Pengingat otomatis untuk janji temu yang akan datang.

### 💊 Layanan Pesan Obat & Farmasi

- **Pesan Obat Instan**: Memesan obat-obatan yang diresepkan atau yang dijual bebas langsung dari aplikasi.
- **Layanan Antar Obat (Delivery)**: Integrasi layanan pengiriman untuk memastikan obat sampai di tangan pasien dengan cepat dan aman.
- **Upload Resep**: Fitur untuk mengunggah foto resep dokter untuk diproses oleh apotek terdekat.

## 📦 Cara Memulai (Installation Guide)

Ikuti panduan ini untuk menginstal dan menjalankan proyek secara lokal.

### Prasyarat

- **Flutter SDK** (Versi stabil terbaru)
- **Git**
- **Web Server** (Contoh: XAMPP, Laragon, atau LAMP/LEMP) dengan dukungan **PHP** dan **MySQL**.

### A. Setup Backend (API Server)

1.  **Kloning Repositori:**
    ```bash
    git clone [https://github.com/feboyfierlyan/good_health.git](https://github.com/feboyfierlyan/good_health.git)
    cd good_health
    ```
2.  **Setup PHP:**
    - Pindahkan folder `goodhealth` di folder `api_server` ke direktori root web server kamu (ke `htdocs`).

### B. Setup Mobile App (Flutter)

1.  **Masuk ke Direktori Flutter:**
    ```bash
    cd good_health
    ```
2.  **Instal Dependensi:**
    ```bash
    flutter pub get
    ```
3.  **Jalankan Aplikasi:**
    ```bash
    flutter run
    ```
    _Atau jalankan dari VS Code dengan memilih perangkat (emulator/fisik) dan menekan **F5**._
